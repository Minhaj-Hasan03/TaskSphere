# TaskSphere

An academic task management system built for students, teachers, and admins to organize coursework, attendance, and reminders in one place.

## Features
- Student registration & login (Email/Password + Google Sign-In)
- Teacher dashboard for courses, sections, attendance, and marks
- Admin panel for overall management
- Syllabus tracking and reminders

## Tech Stack
**Frontend:** React, Vite, Tailwind CSS, React Router, Firebase Auth  
**Backend:** Node.js, Express, MongoDB (Mongoose), JWT
